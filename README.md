# SP-Public-Doc-Collaboration

This public GitHub repository records how Community Newsletters and other public collaboration documents evolve on Strategic Pivot (SP). The **SP Public Collaboration Bot** records submitted revisions and writes accepted changes to the main document. The production repository is the canonical archive; the separate public development repository is for testing.

This archive is not a GitHub template or a place to store private collaboration documents.

You do not need an SP account to exercise those permissions; you do need one to propose revisions in SP.

GitHub commit history records the Bot's writes. SP adds to document records who submitted each version, whether the owner accepted or declined it, and maintains contributor credit as the **version-main.md** file, or main document evolves. All these things are trackable in the file for that specific document. SP also retains its stored Markdown copy of document variants.

Strategic Pivot controls the archive and commits to keeping direct repository writes **Bot-only**. People write, review, and approve document changes in SP, but no person has a direct-write bypass on GitHub. The Bot-only rules protect the integrity of the GitHub archive. They do not restrict anyone from copying or adapting licensed material elsewhere under CC BY 4.0.

### Rules

- **Propose revisions in SP.** Create and submit a version copy on the platform. Do not edit the archive directly or use GitHub pull requests to submit changes. You do not need to install the Bot or request GitHub write access.
- **Review and accept revisions in SP.** The document owner decides which changes to accept. The Bot archives submitted versions and records the accepted text in `version-main.md`.
- **Use the archive to trace changes.** GitHub's history shows what the Bot wrote. SP tracks who submitted each revision and whose work was incorporated. Preserve appropriate contributor credit when reusing licensed material.
- **Submit only material cleared for public release.** Submitted revisions may appear here before they are accepted. Do not submit confidential documents, credentials, or personal information that is not approved for publication. Deleting a file does not recall copies or forks.
- **Preserve the record.** The archive protects `main` against force pushes and branch deletion. The Bot's permission to write ordinary commits does not bypass those protections.
